# LONGWATCH — Book One: The Cadet Cruise

**An interactive space-opera LitRPG that runs in a single HTML file.**
You are a first-year cadet at Longwatch Academy, on the edge of the Reach. A signal that has been silent for four thousand years has started to sing again. Train, fight, choose, level up, and travel six worlds with a squad of four to find out what the Lantern wants.

## Game features

| | |
|---|---|
| **Character** | 4 backgrounds, 5 tracks (Marine, Pilot, Engineer, Tactician, Medic), 5 stats (Might, Reflex, Intellect, Resolve, Presence), levels 1–25 |
| **Skills** | 52 skills: active, passive and check-based, with track skills and cross-training |
| **Combat** | Turn-based, with telegraphed enemy intents, status effects, and 4 damage types (Kinetic, Energy, Plasma, Ion) against enemy resistances |
| **Squad orders** | Free once-per-turn orders from Tamsin, Dex, Kesh and Soren, scaled by your Presence and bond |
| **Ship combat** | Gunnery encounters against pirates, interceptors, Hollow needles and a Dreadnought |
| **Enemies** | 60 enemy types including 13 bosses, each with its own moves, weaknesses and phases |
| **Choices** | d20 skill checks (stat + skill + track + bond bonuses), Command Points to reroll, flags that change later scenes |
| **Gear** | Weapons, armor, modules and implants across common → legendary, a Quartermaster that restocks as the story advances, consumables |
| **Bonds** | Mess Hall talks with each squadmate (12 scenes) build bonds that unlock choices and endings |
| **Collections** | 78 achievements (a few hidden), a 35-entry Codex, a Bestiary, a Journal |
| **Replay** | Simulator, sorties against any visited world, and boss rematches |
| **Saves** | Autosave in the browser plus an export/import save code |

## Mobile and accessibility notes

- Built for phone widths, with safe-area insets for notched screens.
- Sticky HUD with HP, shields, focus and XP.
- Text-first design. No audio, no flashing effects.
